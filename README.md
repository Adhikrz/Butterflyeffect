# Butterflyeffect

A browser-only experimental photo skin player.

## Features
- 110 skin names matching the reference workflow
- Original CSS/canvas-based effect approximations
- Search and previous/next navigation
- Drag & drop image loading
- 3:4, 1:1 and 16:9 preview ratios
- Intensity control
- PNG export
- Light/dark mode
- Filter Creator
- Custom filters stored in localStorage
- Export/import custom filter packs
- No backend; images stay in the browser

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
This is a static site. Push the repository and enable GitHub Pages from the repository's Pages settings using GitHub Actions or the main branch.

## Note
This project recreates the visual workflow and filter concepts with independently implemented effects. It does not copy proprietary source code or assets from the reference site.
